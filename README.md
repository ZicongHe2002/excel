# 选款助手

上传商品 Excel，搜索或粘贴客户货号，下载保留完整商品行块的选款表。

## 直接使用

双击本文件夹里的 **选款助手.html**，使用 Chrome、Edge 或 Safari 打开即可，不需要安装软件或启动服务。

1. 上传一份或多份 `.xlsx` 商品资料。
2. 在“查找货号”中逐个搜索，点“加入清单”；也可直接粘贴客户货号，支持换行、空格、逗号、中文逗号和分号分隔。
3. 点击导出，下载选款 Excel。

文件在当前浏览器本机读取和处理，不会上传服务器。刷新或关闭页面后，需要重新选择原文件。

## 发布到 Render

使用 [Render 上传说明](Render上传说明.md) 中的步骤，将 `Render上传包` 内的文件上传到 GitHub，再创建 Render **Static Site**。发布包已经完成构建，无需在 Render 安装 Node 依赖。

- Build Command：`test -s public/index.html`
- Publish Directory：`public`
- Root Directory：留空

开发者修改源代码后，运行 `npm run package:render` 重新生成上传目录和 ZIP。包中只有 `public/index.html`、`render.yaml` 和说明，不含商品 Excel 和测试资料。发布时上传包内文件，不能直接上传 ZIP，也不要上传整个开发目录。

## 搜索和复制货号

- 导入后显示可选货号，可输入完整货号或部分字符查找，不区分字母大小写。清空搜索框会重新显示全部货号。
- 点击“复制货号”可复制单个货号；点击“加入清单”可逐个选款。已经加入的货号不会重复添加。
- 搜索结果只有一个，或输入的货号与某条结果完全一致时，按回车也能加入；按 Esc 清空搜索。
- 同一货号来自多个表时，结果合并显示来源和总行数。加入一次后，导出仍会包含每个来源中的完整商品行。
- 客户货号区域的“复制清单”会复制去重后的完整货号列表，每行一个。货号文字也支持直接选中、复制。
- 搜索用于找到货号；正式导出仍按加入清单的完整货号匹配。例如搜索 `H14` 可以找到 `H140`，点击加入后清单中会写入 `H140`。

## 提取规则

- 一个货号覆盖多少行，就提取完整的多少行，包含所有颜色、尺码、库存、价格、商品介绍及图片。
- 保留原表表头、序号、单元格内容、字体、边框、填充、合并区域、行高和列宽。
- 每份来源的每个匹配工作表单独输出一个工作表，按原表顺序排列商品。
- 多个来源出现同一货号时全部提取，不比较或覆盖价格。
- 重复输入的货号只处理一次，匹配忽略字母大小写；不会模糊匹配或删除货号前缀。
- 未找到的货号明确提示；其余找到的商品可正常导出。
- 原始文件不会被修改。

例如输入 `LR059`，KOKO 原表中的第 2、3 行会一起输出，米色和深灰色均保留。输入 `H140`，KOKO 的 6 行和 Cole 的 5 行会分别出现在两个来源工作表。

## 格式支持

已针对本目录两份原始文件验证。支持表头为“款号 / 货号 / SKU”等字段的普通 `.xlsx` 文件，可识别合并货号和同款连续行。旧版 `.xls`、加密表格须先在 Excel / WPS 中另存为普通 `.xlsx`。

WPS 的单元格图片按原表形式直接复制：原始图像文件、`DISPIMG` 显示公式、图片尺寸、裁切/旋转设置和单元格对应关系全部保留，不重新生成、缩放或压缩图片。不同来源图片标识相同时仅重新关联标识，避免同号图片串图。普通浮动图片保持原来的横向位置和尺寸，随所选行移动。

这两份原表使用 WPS 单元格图片，因此导出的图片表建议在 **WPS** 中打开。macOS 快速预览及不支持 `DISPIMG` 的 Excel 版本可能只显示图片公式；这与原始文件的兼容性一致，不表示图片文件缺失。

这是商品资料提取工具，不是完整 Excel 计算编辑器。普通公式导出为原文件已保存的计算结果；没有结果时会提示先计算并保存。宏、图表、批注、数据验证等不在第一版保留范围内；原表若包含非图片绘图、公式条件格式，会显示提示。复杂模板建议先用少量货号检查一次导出。

单文件上限 80 MB，解压内容上限 250 MB。由于浏览器内存有限，很多大图文件建议分批处理。

## 开发与验证

```bash
npm ci
npm run dev
npm test
npm run build
```

`npm run build` 同时生成根目录的独立 HTML 和 `dist/index.html`。所有脚本、样式和运行依赖都打包进页面，离线也可使用。

测试使用本目录的两份 Excel，逐格比较完整行数据、样式、合并区域、行高列宽，并逐张比较输出图片原始字节、图片对象显示设置与单元格对应关系。还验证跨文件图片标识冲突、多单元格共用一张图，以及普通浮动图位置和文件内部引用。
